在Ubuntu 16系统执行

#### 1.安装miniconda

wget [https://repo.continuum.io/miniconda/Miniconda3-latest-Linux-x86\_64.sh](https://links.jianshu.com/go?to=https%3A%2F%2Frepo.continuum.io%2Fminiconda%2FMiniconda2-latest-Linux-x86_64.sh)

![](/images/posts/0b97e212f24f/10821116-671b87cbf06eb3cf)

image

```
bash Miniconda3-latest-Linux-x86_64.sh
```

![](/images/posts/0b97e212f24f/10821116-0dd6f126ab0cb80b)

image

按照提示按回车键ENTER

![](/images/posts/0b97e212f24f/10821116-4d467323494298fb)

image

输入yes

![](/images/posts/0b97e212f24f/10821116-5b24532370523580)

image

按回车键ENTER，miniconda2将安装在/home/czh/miniconda2 这个路径

![](/images/posts/0b97e212f24f/10821116-0b42ff8f7578c973)

image

安装过程中询问你是否将miniconda2添加到环境变量中，输入yes将自动添加到环境变量中，如果你不小心按了回车键ENTER，则不会自动添加到环境变量中，后面需要自己手动添加。

![](/images/posts/0b97e212f24f/10821116-9b65e8a453cd0855)

image

看见Thank you for installing Miniconda2! 表明安装完毕。现在输入conda检测一下安装成功没，发现报错并没安装成功，因为上一步添加环境变量后，没有刷新环境变量bashrc这个文件，这时候输入 source ~/.bashrc， 再输入conda，则发现无报错安装成功！

```
#设置conda的软件下载频道，华东或华中地区推荐使用中科大镜像，清华镜像也可，根据你的网络所在地选择。

conda config --add channels https://mirrors.ustc.edu.cn/anaconda/pkgs/main/

conda config --add channels https://mirrors.ustc.edu.cn/anaconda/pkgs/free/

conda config --add channels https://mirrors.ustc.edu.cn/anaconda/cloud/conda-forge/

conda config --add channels https://mirrors.ustc.edu.cn/anaconda/cloud/msys2/

conda config --add channels https://mirrors.ustc.edu.cn/anaconda/cloud/bioconda/

conda config --add channels https://mirrors.ustc.edu.cn/anaconda/cloud/menpo/

conda config --add channels r

conda config --add channels defaults

conda config --add channels conda-forge

conda config --add channels bioconda

conda config --set show_channel_urls yes

#查看一下所设置的频道

cat ~/.condarc
```

#### 2.使用miniconda安装软件

```
#以构建转录组分析环境为例，安装转录组拼接软件trinity，先在软件库里搜索trinity。

conda search trinity
```

## 

![](/images/posts/0b97e212f24f/10821116-173496e7fefd36bc)

image

搜索结果显示trinity多个版本和存放频道，conda默认安装最新版本，也可以安装特定版本。

创建名为RNA\_seq的虚拟环境，并安装trinity在该环境中。

```
conda create -n RNA_seq trinity
```

## 

![](/images/posts/0b97e212f24f/10821116-8b2867ed1cc1be3b)

image

过程中会询问你是否下载这些包进行安装，输入y 继续安装。

![](/images/posts/0b97e212f24f/10821116-8e7a00b1a6db7163)

image

出现上述界面表明安装成功

```
#激活RNA_seq虚拟环境

source activate RNA_seq

#检测trinity是否安装成功，无报错出现帮助信息，说明安装成功。

Trinity -h
```

![](/images/posts/0b97e212f24f/10821116-6b4005cfb9ca294f)

image

关闭RNA\_seq虚拟环境

```
source deactivate
```

![](/images/posts/0b97e212f24f/10821116-823ada50dc55e11b)

image

在RNA\_seq虚拟环境中继续安装转录组相关软件bowtie2

```
conda install -n RNA_seq bowtie2
```

![](/images/posts/0b97e212f24f/10821116-ce4eeeae95b8b342)

image

bowtie2安装成功后，再次激活虚拟环境RNA\_seq

```
source activate RNA_seq
```

检测bowtie2安装是否成功

```
bowtie2 -h
```

检测trinity是否正常

```
Trinity -h
```

![](/images/posts/0b97e212f24f/10821116-4d924fcf2923a54e)

image

##### 至此RNA\_seq虚拟环境构建成功，且成功安装两个软件在该环境中。虚拟环境的构建有利于软件流程的管理，如不这样，直接使用conda install “软件名” 也可安装软件，但当使用conda安装软件过多时，容易出现报错，具体原因还不十分清楚。猜测是不同软件的往往存在相同的依赖软件，但依赖软件版本的要求又不尽相同，在软件使用时，软件无法调用正确版本的依赖软件，从而导致错误。
